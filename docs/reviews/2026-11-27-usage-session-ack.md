## 实际验证

- `pnpm --filter @xiaochao/server typecheck`：退出 0。
- `pnpm --filter @xiaochao/server test --maxWorkers=4 --minWorkers=1`：9 个文件、49 项通过，连续两次。`report-store` 中两个原有的时序用例在构建并发、机器高负载时出现过 5 秒超时，单独重跑通过。
- `pnpm test:web`：112 项通过。
- 变异检验：去掉 `insertDataOption` 查询参数、超时判定改为 `>=`、大厅心跳改为进队列、取消本次打开优先，对应测试均失败；恢复后通过。
- 本地真实 Chromium（无头）+ 本地服务（未配飞书，仅写 `LOG_DIR`）：打开首页 0.2 秒发出 `app_open#1`（204），30 秒发出 `heartbeat#2`（204）；直接关闭标签页时 beacon 送达 `heartbeat#3`；约 95 秒后「应用」会话变为「超时结束」，结束时间等于最后一次确认时间。
- 未验证：生产 `https://frp-net.com:59352`（开发机连接后 5 秒内被断开）；飞书在线写入（自动模式拒绝向表格写测试行）；APK 真机；从大厅点进游戏的浏览器路径（无头环境未能稳定操作大厅，由单测覆盖）。

## 链路检查

| 模块 | 输入 | 转换 | 输出 | 结论 |
|---|---|---|---|---|
| H5 统计 | 页面加载、可见性、APK 前后台、进入/离开游戏 | 全局 `seq`，`app_open` 立即发，30 秒心跳，隐藏/关闭时 beacon | `/collect` 文本 JSON 批次 | 通过 |
| `/collect` | v1 批次 | 校验（大厅心跳可不带游戏）、去重、落盘或记回执 | 204；会话跟踪 | 通过 |
| 会话跟踪 | 新收到的事件 | 按会话与游玩累计确认，90 秒超时 | `sessions.json`、飞书「会话」表 | 本地通过，飞书待在线验证 |
| 飞书写入 | 事件批次、会话行 | 查询参数 `INSERT_ROWS`、整列范围、串行请求 | 三张事件表追加，会话表追加后原地更新 | 单测通过，待在线验证 |

## 残余风险

- 生产是否由本服务处理 `/collect`、证书是否有效、飞书变量是否齐全，见设计文档第 7 节。
- 会话表须由运维新建并配置 `FEISHU_SESSION_SHEET_ID`；未配置时只在本地保存会话状态。
- 须先部署服务端再发布客户端；发版默认上报到生产。
