# Runtime Toolbar and Cleanup Design

**Goal:** 修复运行时顶部栏的错误职责和退出残留，让齿轮设置真正驱动模拟器布局，并保证退出后大厅完全可操作。

## Design

- 顶部栏只显示返回、游戏标题、设置和全屏；屏幕宽高、旋转、键盘、主题和布局均由齿轮设置面板负责。
- React 播放器在运行时同步 `config` 的旋转、主题、布局、键盘和全屏适配属性，避免设置修改后外壳仍使用旧布局。
- J2ME 运行时提供可重复调用的清理入口，退出时释放按键、帧调度、FPS interval、wake lock、动态 HUD/调试节点、运行时 body 属性和动态脚本样式；React 再退出全屏并卸载播放器。
- 退出确认完成后才执行清理和路由切换，取消确认保持完整游戏状态。

## Validation

- 构建和静态检查通过。
- 真实服务下验证大厅可点击、运行时设置可打开、竖屏/横屏/全屏可操作、退出后大厅下半屏可点击且无 FPS 残留。
