# 运行时顶部布局修复设计

## 目标

修复冒泡游戏启动后手机壳顶部出现白色空白区域的问题，并移除播放器顶部中间的运行状态工具条。左上角返回按钮和退出确认流程继续保留。

## 方案

- 删除 `Player` 中的 `.runtimeToolbar` 节点，避免顶部出现额外的悬浮工具条。
- 让运行时视口覆盖播放器完整区域，不再为已移除的工具条预留顶部偏移。
- 将 J2ME 编辑层固定为绝对定位、透明且不参与正常布局。只有编辑控件显示时才覆盖到画布上，避免隐藏控件生成白色占位块。
- 保留手机壳内部的 `deviceStatus`，其状态栏仍由手机壳自己的布局管理。

## 影响范围

- `apps/web/src/App.jsx`：播放器结构。
- `apps/web/uno.config.js`：运行时视口快捷样式。
- `runtime/j2me/style/main.css` 与 `runtime/j2me/style/lcdui.css`：手机壳和编辑层定位。

## 验证

在竖屏移动尺寸下启动冒泡游戏，确认顶部没有白色区域，画布从状态栏下方正常开始，按键区和返回按钮仍可操作。再确认退出后大厅可正常加载。
