# 模拟器工具栏与设置面板修复设计

## 目标

修复 J2ME 模拟器顶部设置入口偶尔无响应、设置面板在手机上不能顺畅滚动，以及固定工具栏覆盖模拟器画面的情况。

## 方案

React 工具栏仅在 J2ME 运行时脚本完成初始化且设置面板节点可用后启用设置入口，并通过现有齿轮事件打开游戏设置。工具栏继续固定显示，但播放器为其预留顶部空间，确保模拟器内容不被遮挡。手机设置面板使用扣除安全区后的视口高度作为滚动容器，保留面板内部纵向触摸滚动。

## 验收标准

- 运行时未完成初始化时，设置入口不可触发空操作；就绪后一次点击即可开关现有设置面板。
- 手机竖屏中工具栏不覆盖模拟器画面。
- 设置面板内容超出屏幕时可纵向触摸滚动，底部操作仍可到达。
- 桌面及横屏工具栏和面板布局保持可用。
