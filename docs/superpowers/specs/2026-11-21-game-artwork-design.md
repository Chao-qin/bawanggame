# 游戏封面与入库

- **目标：** 安装时保留标题、游戏包和可用封面；热门、最近与详情复用游戏库图片。
- **范围：** Flash、J2ME/52java、冒泡目录及 Flash 商城间距。目录浏览不预下载游戏包。
- **兼容：** 图片缺失不阻断安装。旧记录仅按来源 ID 或运行时标识补图，不按同名猜测，不改游戏数据、去重规则或存档。
- **验收：** 安装后重载和离线仍可显示已保存图片；缺图仍可启动；Flash 首条结果与搜索分隔且图片完整。分别记录 Chromium 与 Android WebView 验证。

优先使用来源缩略图，其次使用包内图标，最后显示首字。新增封面字段必须可选；读取历史记录时优先关联本机元数据，不持久化临时对象 URL。限制图片大小和类型，图片失败与游戏包失败分别处理。

同一 PR 排查 J2ME 竖屏只显示压扁数字键的情况。分别验证默认和自定义布局；默认布局中方向键、软键和数字键均可操作，游戏画面不被遮挡，`#` 等按键映射不变。
