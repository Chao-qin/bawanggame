# Fruit Madness

Fruit Madness is a complete ActionScript 3 arcade game by Vladimir Belyaev. Its upstream README says the compiled SWF runs in Ruffle.

The game moves with the arrow keys or WASD. Start it from the title screen with the mouse or touch.
